## 1.1 后端意图识别升级

### 1.1.1 现状分析

当前 `logic/task_parser.py` 中的 `parse_command` 函数通过关键词正则匹配实现意图路由，典型实现如下：

```python
# 现状：关键词正则匹配
def parse_command(task, history=None, location=None):
    task_lower = task.lower()

    # 天气意图
    if re.search(r'(天气|气温|下雨|刮风|雾霾)', task_lower):
        return handle_weather(task, location)

    # 音乐意图
    if re.search(r'(播放|来一首|放一首|听.*歌)', task_lower):
        return handle_music(task)

    # 文生图意图
    if re.search(r'(画|生成.*图|画.*画)', task_lower):
        return handle_image_generation(task)

    # 本机应用
    if re.search(r'(打开|启动|运行)', task_lower):
        return launch_local_app(task)

    # 兜底：AI 对话
    return handle_chat(task, history)
```

**存在的问题**：

| 问题 | 影响 |
|------|------|
| 规则顺序敏感 | 新增意图需小心插入位置，否则被前置规则误匹配 |
| 边界模糊 | "帮我画一个天气图标" 会被天气规则误拦截 |
| 扩展成本高 | 每加一个功能需手写正则，且需考虑与其他规则的冲突 |
| 无置信度 | 无法区分"确定匹配"和"勉强匹配"，无法触发澄清反问 |
| 多意图无法处理 | "查天气然后播放音乐" 只能匹配第一个命中的规则 |

### 1.1.2 优化目标

- 引入 LLM 意图分类，利用已有的 DashScope 能力，将意图识别准确率提升至 95%+
- 保留规则匹配作为兜底和快速通道（高频意图无需 LLM 调用）
- 支持多意图识别和置信度输出
- 新增意图只需修改配置，无需改动路由逻辑

### 1.1.3 技术方案

采用 **LLM 意图分类 + 规则兜底 + 意图缓存** 三层架构：

```
用户输入
  │
  ▼
┌──────────────┐    命中     ┌──────────────┐
│  规则快速通道  │ ─────────→ │  直接路由执行  │
│  (高频意图)   │            └──────────────┘
└──────┬───────┘
       │ 未命中
       ▼
┌──────────────┐    命中     ┌──────────────┐
│  意图缓存查询  │ ─────────→ │  直接路由执行  │
│  (相似输入)   │            └──────────────┘
└──────┬───────┘
       │ 未命中
       ▼
┌──────────────┐  高置信度   ┌──────────────┐
│  LLM 意图分类 │ ─────────→ │  路由执行     │
│  (DashScope) │            └──────────────┘
└──────┬───────┘
       │ 低置信度
       ▼
┌──────────────┐
│  澄清反问     │
│  (让用户确认) │
└──────────────┘
```

#### 1.1.4.2 LLM 意图分类器

创建 `backend/logic/intent_classifier.py`：

```python
# backend/logic/intent_classifier.py
import json
import hashlib
import requests
from typing import Optional, Tuple
from config.intents import INTENTS

class IntentClassifier:
    """基于 LLM 的意图分类器，带缓存和规则兜底"""

    def __init__(self, api_key: str, cache_size: int = 500):
        self.api_key = api_key
        self.cache = {}  # 简单内存缓存：hash(input) -> (intent_name, confidence)
        self.cache_size = cache_size

    def _build_classification_prompt(self, user_input: str) -> str:
        """构建 few-shot 分类 prompt"""
        intent_list = "\n".join([
            f"- {i.name}: {i.description}"
            for i in INTENTS if i.name != "chat"
        ])

        return f"""你是一个意图分类器。分析用户输入，判断属于以下哪种意图。

## 可用意图
{intent_list}
- chat: 以上都不匹配时的通用对话

## 分类规则
1. 只返回 JSON 格式：{{"intent": "意图名", "confidence": 0.0-1.0}}
2. 如果用户输入包含多个意图，返回最主要的一个
3. 如果无法确定意图，返回 intent="chat", confidence<0.5
4. 不要返回任何其他内容

## 示例
用户: "北京今天天气怎么样"
输出: {{"intent": "weather", "confidence": 0.98}}

用户: "帮我画一只小猫"
输出: {{"intent": "image_generation", "confidence": 0.95}}

用户: "今天心情不太好"
输出: {{"intent": "chat", "confidence": 0.9}}

用户: "播放周杰伦的稻香"
输出: {{"intent": "music", "confidence": 0.97}}

现在请分类以下输入：
用户: "{user_input}"
输出:"""

    def _call_llm(self, prompt: str) -> dict:
        """调用 DashScope 进行分类"""
        response = requests.post(
            "https://dashscope.aliyuncs.com/compatible-mode/v1/chat/completions",
            headers={
                "Authorization": f"Bearer {self.api_key}",
                "Content-Type": "application/json",
            },
            json={
                "model": "qwen-turbo",  # 使用轻量模型，降低成本
                "messages": [{"role": "user", "content": prompt}],
                "temperature": 0.1,     # 低温度，保证分类稳定
                "max_tokens": 100,
            },
            timeout=5,
        )
        result = response.json()
        content = result["choices"][0]["message"]["content"]
        # 提取 JSON
        content = content.strip()
        if content.startswith("```"):
            content = content.split("\n", 1)[1].rsplit("\n", 1)[0]
        return json.loads(content)

    def _rule_match(self, user_input: str) -> Optional[Tuple[str, float]]:
        """规则快速匹配（高频意图优先）"""
        import re
        sorted_intents = sorted(INTENTS, key=lambda x: x.priority, reverse=True)
        for intent in sorted_intents:
            if not intent.keywords:
                continue
            for kw in intent.keywords:
                if re.search(kw, user_input.lower()):
                    return (intent.name, 0.85)
        return None

    def _cache_key(self, user_input: str) -> str:
        return hashlib.md5(user_input.encode()).hexdigest()

    def classify(self, user_input: str) -> Tuple[str, float]:
        """
        分类用户输入，返回 (意图名, 置信度)
        三层策略：规则 → 缓存 → LLM
        """
        # 第一层：规则快速通道
        rule_result = self._rule_match(user_input)
        if rule_result:
            return rule_result

        # 第二层：缓存查询
        cache_key = self._cache_key(user_input)
        if cache_key in self.cache:
            return self.cache[cache_key]

        # 第三层：LLM 分类
        try:
            prompt = self._build_classification_prompt(user_input)
            result = self._call_llm(prompt)
            intent_name = result.get("intent", "chat")
            confidence = float(result.get("confidence", 0.5))

            # 验证意图名有效性
            valid_names = {i.name for i in INTENTS}
            if intent_name not in valid_names:
                intent_name = "chat"
                confidence = 0.3

            # 写入缓存
            if len(self.cache) >= self.cache_size:
                # 简单 FIFO 淘汰
                self.cache.pop(next(iter(self.cache)))
            self.cache[cache_key] = (intent_name, confidence)

            return (intent_name, confidence)

        except Exception as e:
            # LLM 调用失败，降级为 chat
            return ("chat", 0.3)
```

```python
# backend/logic/task_parser.py（改造后）
from logic.intent_classifier import IntentClassifier
from config.intents import INTENTS
import os

# 初始化分类器（在 app.py 中创建并注入）
classifier = IntentClassifier(api_key=os.getenv("DASHSCOPE_API_KEY"))

# 意图 → 处理函数映射
INTENT_HANDLERS = {
    "weather": handle_weather,
    "music": handle_music,
    "image_generation": handle_image_generation,
    "chart": handle_chart,
    "app_launch": launch_local_app,
    "translation": handle_translation,
    "chat": handle_chat,
}

# 需要澄清的置信度阈值
CLARIFY_THRESHOLD = 0.6

def parse_command(task, history=None, location=None):
    """改造后的意图解析入口"""
    intent_name, confidence = classifier.classify(task)

    # 低置信度 → 澄清反问
    if confidence < CLARIFY_THRESHOLD:
        return {
            "type": "clarify",
            "msg": f"我不太确定你的意思，你是想：\n"
                   f"1. 查询天气\n2. 播放音乐\n3. AI 对话\n"
                   f"请告诉我具体需求～",
            "intent": intent_name,
            "confidence": confidence,
        }

    # 路由到对应处理函数
    handler = INTENT_HANDLERS.get(intent_name, handle_chat)
    return handler(task, history=history, location=location)

## 1.2 对话智能化增强

### 1.2.1 现状分析

当前多轮对话通过前端 `history` 数组传递消息，后端直接拼接后发给 LLM：

```python
# 现状：简单拼接历史
def handle_chat(task, history=None):
    messages = [{"role": "system", "content": SYSTEM_PROMPT}]
    if history:
        for msg in history[-12:]:  # 只保留最近 12 条
            messages.append(msg)
    messages.append({"role": "user", "content": task})
    return call_llm(messages)
```

**存在的问题**：

| 问题 | 表现 |
|------|------|
| 上下文截断粗暴 | 固定保留最近 N 条，可能截断关键信息 |
| 无记忆压缩 | 长对话中 token 持续增长，超出模型窗口 |
| 无意图澄清 | 模糊输入直接丢给 LLM，容易答非所问 |
| 无对话状态 | 无法追踪用户当前在哪个功能场景中 |
| 无话题切换检测 | 用户突然换话题时，旧上下文仍被携带 |

### 1.2.2 优化目标

- 实现滑动窗口 + 摘要压缩的上下文管理
- 引入对话状态机，追踪用户当前场景
- 支持意图澄清反问机制
- 话题切换时自动清理无关上下文

### 1.2.3 技术方案

采用 **DialogueManager** 统一管理对话生命周期：

```
用户输入
  │
  ▼
┌──────────────────┐
│  话题切换检测      │ ← 检测是否切换话题
└────────┬─────────┘
         │
         ▼
┌──────────────────┐
│  上下文窗口管理    │ ← 滑动窗口 + 摘要压缩
└────────┬─────────┘
         │
         ▼
┌──────────────────┐
│  系统提示构建      │ ← 注入用户偏好 + 对话状态
└────────┬─────────┘
         │
         ▼
┌──────────────────┐
│  LLM 调用         │
└────────┬─────────┘
         │
         ▼
┌──────────────────┐
│  响应后处理        │ ← 更新状态、生成摘要
└──────────────────┘
```

### 1.2.4 实现要点

#### 1.2.4.1 对话管理器

创建 `backend/logic/dialogue_manager.py`：

```python
# backend/logic/dialogue_manager.py
from dataclasses import dataclass, field
from typing import List, Dict, Optional
from enum import Enum
import hashlib
import time

class DialogueState(Enum):
    IDLE = "idle"               # 空闲，等待用户输入
    CLARIFYING = "clarifying"   # 正在澄清用户意图
    IN_TASK = "in_task"         # 正在执行某个任务
    AWAITING_CONFIRM = "awaiting_confirm"  # 等待用户确认

@dataclass
class DialogueTurn:
    role: str           # "user" | "assistant"
    content: str
    timestamp: float = field(default_factory=time.time)
    intent: Optional[str] = None
    token_count: int = 0

@dataclass
class DialogueSession:
    session_id: str
    turns: List[DialogueTurn] = field(default_factory=list)
    state: DialogueState = DialogueState.IDLE
    current_intent: Optional[str] = None
    summary: str = ""           # 历史对话摘要
    topic_embedding: str = ""   # 当前话题的简化指纹

class DialogueManager:
    """对话管理器：上下文窗口、摘要压缩、状态追踪"""

    MAX_WINDOW_TURNS = 20       # 滑动窗口最大轮次
    MAX_WINDOW_TOKENS = 6000    # 滑动窗口最大 token 数（估算）
    SUMMARY_TRIGGER_TURNS = 10  # 超过此轮次触发摘要压缩
    TOPIC_SWITCH_THRESHOLD = 0.3  # 话题相似度阈值

    def __init__(self):
        self.sessions: Dict[str, DialogueSession] = {}

    def get_or_create_session(self, session_id: str) -> DialogueSession:
        if session_id not in self.sessions:
            self.sessions[session_id] = DialogueSession(session_id=session_id)
        return self.sessions[session_id]

    def add_turn(self, session_id: str, role: str, content: str,
                 intent: Optional[str] = None):
        """添加一轮对话"""
        session = self.get_or_create_session(session_id)
        turn = DialogueTurn(
            role=role,
            content=content,
            intent=intent,
            token_count=self._estimate_tokens(content),
        )
        session.turns.append(turn)

        # 更新状态
        if intent:
            session.current_intent = intent
            session.state = DialogueState.IN_TASK

        # 检查是否需要压缩
        if len(session.turns) > self.SUMMARY_TRIGGER_TURNS:
            self._compress_history(session)

    def build_context(self, session_id: str,
                      system_prompt: str = "",
                      user_preferences: Optional[dict] = None) -> List[dict]:
        """构建发送给 LLM 的完整消息列表"""
        session = self.get_or_create_session(session_id)

        messages = []

        # 1. 系统提示
        enhanced_prompt = self._build_system_prompt(
            system_prompt, session, user_preferences
        )
        messages.append({"role": "system", "content": enhanced_prompt})

        # 2. 历史摘要（如果有）
        if session.summary:
            messages.append({
                "role": "system",
                "content": f"[历史对话摘要] {session.summary}"
            })

        # 3. 滑动窗口内的最近对话
        recent_turns = self._get_recent_turns(session)
        for turn in recent_turns:
            messages.append({"role": turn.role, "content": turn.content})

        return messages

    def _build_system_prompt(self, base_prompt: str,
                             session: DialogueSession,
                             preferences: Optional[dict]) -> str:
        """构建增强版系统提示"""
        parts = [base_prompt]

        # 注入对话状态
        if session.state != DialogueState.IDLE:
            parts.append(f"\n当前对话状态：{session.state.value}")
        if session.current_intent:
            parts.append(f"当前意图：{session.current_intent}")

        # 注入用户偏好
        if preferences:
            pref_str = ", ".join([
                f"{k}: {v}" for k, v in preferences.items()
            ])
            parts.append(f"\n用户偏好：{pref_str}")

        return "\n".join(parts)

    def _get_recent_turns(self, session: DialogueSession) -> List[DialogueTurn]:
        """获取滑动窗口内的最近对话"""
        turns = session.turns
        selected = []
        total_tokens = 0

        # 从最新往前取，直到达到 token 上限
        for turn in reversed(turns):
            if len(selected) >= self.MAX_WINDOW_TURNS:
                break
            if total_tokens + turn.token_count > self.MAX_WINDOW_TOKENS:
                break
            selected.append(turn)
            total_tokens += turn.token_count

        return list(reversed(selected))

    def _compress_history(self, session: DialogueSession):
        """压缩历史对话为摘要"""
        # 保留最近 6 轮，其余压缩为摘要
        if len(session.turns) <= self.SUMMARY_TRIGGER_TURNS:
            return

        old_turns = session.turns[:-6]
        recent_turns = session.turns[-6:]

        # 构建压缩 prompt
        history_text = "\n".join([
            f"{t.role}: {t.content}" for t in old_turns
        ])

        # 调用 LLM 生成摘要（简化版，实际应调用 DashScope）
        summary = self._generate_summary(history_text)

        # 更新 session
        session.summary = summary
        session.turns = recent_turns

    def _generate_summary(self, history_text: str) -> str:
        """调用 LLM 生成对话摘要"""
        import requests, os, json

        prompt = f"""请用 2-3 句话总结以下对话的核心内容和关键信息：

{history_text}

摘要："""

        try:
            response = requests.post(
                "https://dashscope.aliyuncs.com/compatible-mode/v1/chat/completions",
                headers={
                    "Authorization": f"Bearer {os.getenv('DASHSCOPE_API_KEY')}",
                    "Content-Type": "application/json",
                },
                json={
                    "model": "qwen-turbo",
                    "messages": [{"role": "user", "content": prompt}],
                    "max_tokens": 200,
                },
                timeout=10,
            )
            return response.json()["choices"][0]["message"]["content"]
        except Exception:
            return ""

    def detect_topic_switch(self, session_id: str, new_input: str) -> bool:
        """检测是否发生话题切换"""
        session = self.get_or_create_session(session_id)
        if len(session.turns) < 2:
            return False

        # 简化版：基于意图变化判断
        # 完整版应使用 embedding 相似度计算
        last_user_turns = [
            t for t in session.turns[-4:] if t.role == "user"
        ]
        if not last_user_turns:
            return False

        # 如果新输入与最近用户消息的意图不同，视为话题切换
        return True  # 简化实现，实际应基于语义相似度

    def clear_topic_context(self, session_id: str):
        """话题切换时清理上下文"""
        session = self.get_or_create_session(session_id)
        # 保留摘要，清空对话轮次
        if session.turns:
            self._compress_history(session)
        session.state = DialogueState.IDLE
        session.current_intent = None

    @staticmethod
    def _estimate_tokens(text: str) -> int:
        """估算 token 数（中文约 1.5 字符/token，英文约 4 字符/token）"""
        chinese_chars = sum(1 for c in text if '\u4e00' <= c <= '\u9fff')
        other_chars = len(text) - chinese_chars
        return int(chinese_chars / 1.5 + other_chars / 4)
```

## 2.1 JWT 用户认证系统

### 2.1.1 现状分析

当前项目无任何用户认证机制，所有请求共享同一会话空间。前端通过 `localStorage` 存储指令历史和音色偏好，后端 `session.py` 中的 `WORLD_STATE` 等状态绑定在 Flask 进程内存中。这意味着：

- 无法区分不同用户，所有对话历史混在一起
- API 接口完全开放，任何人可调用
- 用户偏好无法跨设备同步
- 重启后端丢失所有会话状态

### 2.1.2 优化目标

- 实现基于 JWT 的用户注册/登录系统
- 保护所有 `/api/*` 接口，未登录用户只能访问登录/注册接口
- 前端实现登录页 + 路由守卫 + AuthContext
- 用户数据持久化到 SQLite 数据库

# backend/models/user.py
import sqlite3
import bcrypt
from datetime import datetime
from pathlib import Path

DB_PATH = Path(__file__).parent.parent / "data" / "xiaowen.db"

def init_db():
    """初始化数据库表"""
    DB_PATH.parent.mkdir(parents=True, exist_ok=True)
    conn = sqlite3.connect(str(DB_PATH))
    cursor = conn.cursor()

    cursor.execute("""
        CREATE TABLE IF NOT EXISTS users (
            id INTEGER PRIMARY KEY AUTOINCREMENT,
            username TEXT UNIQUE NOT NULL,
            password_hash TEXT NOT NULL,
            display_name TEXT DEFAULT '',
            created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
            updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
        )
    """)

    cursor.execute("""
        CREATE TABLE IF NOT EXISTS user_preferences (
            id INTEGER PRIMARY KEY AUTOINCREMENT,
            user_id INTEGER NOT NULL,
            pref_key TEXT NOT NULL,
            pref_value TEXT DEFAULT '',
            updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
            FOREIGN KEY (user_id) REFERENCES users(id),
            UNIQUE(user_id, pref_key)
        )
    """)

    cursor.execute("""
        CREATE TABLE IF NOT EXISTS conversation_history (
            id INTEGER PRIMARY KEY AUTOINCREMENT,
            user_id INTEGER NOT NULL,
            session_id TEXT NOT NULL,
            role TEXT NOT NULL,
            content TEXT NOT NULL,
            intent TEXT DEFAULT '',
            created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
            FOREIGN KEY (user_id) REFERENCES users(id)
        )
    """)

    conn.commit()
    conn.close()

def get_db():
    """获取数据库连接"""
    conn = sqlite3.connect(str(DB_PATH))
    conn.row_factory = sqlite3.Row
    return conn

class UserModel:
    @staticmethod
    def create(username: str, password: str, display_name: str = "") -> dict:
        """创建用户"""
        conn = get_db()
        password_hash = bcrypt.hashpw(
            password.encode('utf-8'), bcrypt.gensalt()
        ).decode('utf-8')

        try:
            cursor = conn.execute(
                "INSERT INTO users (username, password_hash, display_name) VALUES (?, ?, ?)",
                (username, password_hash, display_name)
            )
            conn.commit()
            user_id = cursor.lastrowid
            return {"id": user_id, "username": username, "display_name": display_name}
        except sqlite3.IntegrityError:
            return None  # 用户名已存在
        finally:
            conn.close()

    @staticmethod
    def authenticate(username: str, password: str) -> dict:
        """验证用户登录"""
        conn = get_db()
        row = conn.execute(
            "SELECT * FROM users WHERE username = ?", (username,)
        ).fetchone()
        conn.close()

        if row and bcrypt.checkpw(
            password.encode('utf-8'), row["password_hash"].encode('utf-8')
        ):
            return {
                "id": row["id"],
                "username": row["username"],
                "display_name": row["display_name"],
            }
        return None

    @staticmethod
    def get_by_id(user_id: int) -> dict:
        """根据 ID 获取用户"""
        conn = get_db()
        row = conn.execute(
            "SELECT id, username, display_name, created_at FROM users WHERE id = ?",
            (user_id,)
        ).fetchone()
        conn.close()
        return dict(row) if row else None
```

from models.user import UserModel, init_db
from datetime import timedelta

auth_bp = Blueprint("auth", __name__, url_prefix="/api/auth")

@auth_bp.route("/register", methods=["POST"])
def register():
    """用户注册"""
    data = request.get_json()
    username = data.get("username", "").strip()
    password = data.get("password", "").strip()
    display_name = data.get("displayName", username)

    if not username or not password:
        return jsonify({"error": "用户名和密码不能为空"}), 400
    if len(password) < 6:
        return jsonify({"error": "密码长度至少 6 位"}), 400
    if len(username) < 2 or len(username) > 20:
        return jsonify({"error": "用户名长度 2-20 位"}), 400

    user = UserModel.create(username, password, display_name)
    if user is None:
        return jsonify({"error": "用户名已存在"}), 409

    # 注册成功，直接生成 token
    token = create_access_token(
        identity=str(user["id"]),
        expires_delta=timedelta(days=7),
        additional_claims={
            "username": user["username"],
            "display_name": user["display_name"],
        }
    )

    return jsonify({
        "token": token,
        "user": user,
    }), 201

@auth_bp.route("/login", methods=["POST"])
def login():
    """用户登录"""
    data = request.get_json()
    username = data.get("username", "").strip()
    password = data.get("password", "").strip()

    user = UserModel.authenticate(username, password)
    if user is None:
        return jsonify({"error": "用户名或密码错误"}), 401

    token = create_access_token(
        identity=str(user["id"]),
        expires_delta=timedelta(days=7),
        additional_claims={
            "username": user["username"],
            "display_name": user["display_name"],
        }
    )

    return jsonify({
        "token": token,
        "user": user,
    })

@auth_bp.route("/me", methods=["GET"])
@jwt_required()
def get_current_user():
    """获取当前登录用户信息"""
    user_id = int(get_jwt_identity())
    user = UserModel.get_by_id(user_id)
    if user is None:
        return jsonify({"error": "用户不存在"}), 404

// src/contexts/AuthContext.jsx
import { createContext, useContext, useState, useEffect, useCallback } from 'react';
import { apiFetch } from '../apiBase';

const AuthContext = createContext(null);

export function AuthProvider({ children }) {
  const [user, setUser] = useState(null);
  const [token, setToken] = useState(() => localStorage.getItem('token'));
  const [loading, setLoading] = useState(true);

  // 初始化时验证 token
  useEffect(() => {
    if (token) {
      apiFetch('/api/auth/me', {
        headers: { Authorization: `Bearer ${token}` }
      })
        .then(res => res.json())
        .then(data => {
          if (data.user) {
            setUser(data.user);
          } else {
            logout();
          }
        })
        .catch(() => logout())
        .finally(() => setLoading(false));
    } else {
      setLoading(false);
    }
  }, [token]);

  const login = useCallback(async (username, password) => {
    const res = await apiFetch('/api/auth/login', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({ username, password }),
    });
    const data = await res.json();
    if (data.token) {
      localStorage.setItem('token', data.token);
      setToken(data.token);
      setUser(data.user);
      return { success: true };
    }
    return { success: false, error: data.error };
  }, []);

  const register = useCallback(async (username, password, displayName) => {
    const res = await apiFetch('/api/auth/register', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({ username, password, displayName }),
    });
    const data = await res.json();
    if (data.token) {
      localStorage.setItem('token', data.token);
      setToken(data.token);
      setUser(data.user);
      return { success: true };
    }
    return { success: false, error: data.error };
  }, []);

  const logout = useCallback(() => {
    localStorage.removeItem('token');
    setToken(null);
    setUser(null);
  }, []);

  return (
    <AuthContext.Provider value={{ user, token, loading, login, register, logout }}>
      {children}
    </AuthContext.Provider>
  );
}

export function useAuth() {
  const ctx = useContext(AuthContext);
  if (!ctx) throw new Error('useAuth must be used within AuthProvider');
  return ctx;
}

# backend/ws_server.py
from flask_socketio import SocketIO, emit, join_room, leave_room
from flask_jwt_extended import decode_token
from datetime import datetime

socketio = SocketIO(cors_allowed_origins="*")

# 在线用户映射：user_id -> set of session_ids
online_users = {}

@socketio.on("connect")
def handle_connect():
    """WebSocket 连接建立，验证 token"""
    token = request.args.get("token")
    if not token:
        return False  # 拒绝连接

    try:
        decoded = decode_token(token)
        user_id = decoded["sub"]
        # 将用户加入个人房间
        join_room(f"user_{user_id}")

        if user_id not in online_users:
            online_users[user_id] = set()
        online_users[user_id].add(request.sid)

        emit("connected", {"status": "ok", "user_id": user_id})
    except Exception:
        return False

@socketio.on("disconnect")
def handle_disconnect():
    """连接断开"""
    for user_id, sessions in online_users.items():
        if request.sid in sessions:
            sessions.remove(request.sid)
            if not sessions:
                del online_users[user_id]
            break

@socketio.on("sync_request")
def handle_sync_request(data):
    """客户端请求同步数据"""
    user_id = data.get("user_id")
    last_sync = data.get("last_sync_timestamp", 0)

    # 从数据库获取增量数据
    conn = get_db()
    rows = conn.execute(
        """SELECT * FROM conversation_history
           WHERE user_id = ? AND created_at > ?""",
        (user_id, last_sync)
    ).fetchall()
    conn.close()

    emit("sync_response", {
        "conversations": [dict(r) for r in rows],
        "server_timestamp": datetime.now().isoformat(),
    })

def broadcast_to_user(user_id, event, data):
    """向指定用户的所有设备广播消息"""
    socketio.emit(event, data, room=f"user_{user_id}")

import { useEffect, useRef, useCallback } from 'react';
import { io } from 'socket.io-client';

export function useWebSocket(token) {
  const socketRef = useRef(null);
  const handlersRef = useRef({});

  useEffect(() => {
    if (!token) return;

    const socket = io('http://127.0.0.1:5001', {
      query: { token },
      transports: ['websocket'],
    });

    socket.on('connect', () => {
      console.log('[WS] Connected');
    });

    socket.on('sync_response', (data) => {
      handlersRef.current['sync_response']?.(data);
    });

    socket.on('new_message', (data) => {
      handlersRef.current['new_message']?.(data);
    });

    socket.on('disconnect', () => {
      console.log('[WS] Disconnected');
    });

    socketRef.current = socket;

    return () => {
      socket.disconnect();
    };
  }, [token]);

  const on = useCallback((event, handler) => {
    handlersRef.current[event] = handler;
  }, []);

  const emit = useCallback((event, data) => {
    socketRef.current?.emit(event, data);
  }, []);

  return { on, emit };
}

#### 3.1.4.2 ThemeContext

```jsx
// src/contexts/ThemeContext.jsx
import { createContext, useContext, useState, useEffect, useCallback } from 'react';

const ThemeContext = createContext(null);

const STORAGE_KEY = 'xiaowen-theme';
const THEMES = ['light', 'dark', 'auto'];

function getSystemTheme() {
  return window.matchMedia('(prefers-color-scheme: dark)').matches
    ? 'dark' : 'light';
}

function resolveTheme(theme) {
  return theme === 'auto' ? getSystemTheme() : theme;
}

export function ThemeProvider({ children }) {
  const [theme, setThemeState] = useState(() => {
    return localStorage.getItem(STORAGE_KEY) || 'auto';
  });
  const [resolved, setResolved] = useState(() => resolveTheme(theme));

  const setTheme = useCallback((newTheme) => {
    if (!THEMES.includes(newTheme)) return;
    setThemeState(newTheme);
    localStorage.setItem(STORAGE_KEY, newTheme);
  }, []);

  // 应用到 DOM
  useEffect(() => {
    const actual = resolveTheme(theme);
    setResolved(actual);
    document.documentElement.setAttribute('data-theme', actual);
  }, [theme]);

  // 监听系统主题变化
  useEffect(() => {
    const mq = window.matchMedia('(prefers-color-scheme: dark)');
    const handler = () => {
      if (theme === 'auto') {
        const actual = getSystemTheme();
        setResolved(actual);
        document.documentElement.setAttribute('data-theme', actual);
      }
    };
    mq.addEventListener('change', handler);
    return () => mq.removeEventListener('change', handler);
  }, [theme]);

  return (
    <ThemeContext.Provider value={{ theme, setTheme, resolved }}>
      {children}
    </ThemeContext.Provider>
  );
}

export function useTheme() {
  const ctx = useContext(ThemeContext);
  if (!ctx) throw new Error('useTheme must be used within ThemeProvider');
  return ctx;
}

// src/components/LoginParticleBg.jsx
import { useEffect, useRef } from 'react';
import * as THREE from 'three';

export default function LoginParticleBg() {
  const containerRef = useRef(null);
  const mouseRef = useRef({ x: 0, y: 0 });

  useEffect(() => {
    const container = containerRef.current;
    if (!container) return;

    // ===== 场景初始化 =====
    const scene = new THREE.Scene();
    const camera = new THREE.PerspectiveCamera(
      60,
      container.clientWidth / container.clientHeight,
      0.1,
      1000
    );
    camera.position.z = 30;

    const renderer = new THREE.WebGLRenderer({
      antialias: true,
      alpha: true,  // 透明背景
    });
    renderer.setSize(container.clientWidth, container.clientHeight);
    renderer.setPixelRatio(Math.min(window.devicePixelRatio, 2)); // 性能限制
    container.appendChild(renderer.domElement);

    // ===== 创建粒子系统 =====
    const particleCount = 800;
    const geometry = new THREE.BufferGeometry();
    const positions = new Float32Array(particleCount * 3);
    const colors = new Float32Array(particleCount * 3);
    const sizes = new Float32Array(particleCount);

    // 配色方案
    const palette = [
      new THREE.Color('#4A90D9'), // 主色蓝
      new THREE.Color('#7C5CFC'), // 紫色
      new THREE.Color('#00D4AA'), // 青绿
      new THREE.Color('#FFFFFF'), // 白色星光
    ];

    for (let i = 0; i < particleCount; i++) {
      // 球形分布
      const radius = 15 + Math.random() * 20;
      const theta = Math.random() * Math.PI * 2;
      const phi = Math.random() * Math.PI;

      positions[i * 3] = radius * Math.sin(phi) * Math.cos(theta);
      positions[i * 3 + 1] = radius * Math.sin(phi) * Math.sin(theta);
      positions[i * 3 + 2] = radius * Math.cos(phi) - 5;

      // 随机颜色
      const color = palette[Math.floor(Math.random() * palette.length)];
      colors[i * 3] = color.r;
      colors[i * 3 + 1] = color.g;
      colors[i * 3 + 2] = color.b;

      // 随机大小
      sizes[i] = Math.random() * 0.15 + 0.05;
    }

    geometry.setAttribute('position', new THREE.BufferAttribute(positions, 3));
    geometry.setAttribute('color', new THREE.BufferAttribute(colors, 3));
    geometry.setAttribute('size', new THREE.BufferAttribute(sizes, 1));

    // 圆形粒子纹理
    const canvas = document.createElement('canvas');
    canvas.width = 32;
    canvas.height = 32;
    const ctx = canvas.getContext('2d');
    const gradient = ctx.createRadialGradient(16, 16, 0, 16, 16, 16);
    gradient.addColorStop(0, 'rgba(255,255,255,1)');
    gradient.addColorStop(0.3, 'rgba(255,255,255,0.8)');
    gradient.addColorStop(1, 'rgba(255,255,255,0)');
    ctx.fillStyle = gradient;
    ctx.fillRect(0, 0, 32, 32);

    const texture = new THREE.CanvasTexture(canvas);

    const material = new THREE.PointsMaterial({
      size: 0.4,
      map: texture,
      blending: THREE.AdditiveBlending,
      depthWrite: false,
      vertexColors: true,
      transparent: true,
      opacity: 0.8,
    });

    const particles = new THREE.Points(geometry, material);
    scene.add(particles);

    // ===== 动画循环 =====
    let frameId;
    const animate = () => {
      frameId = requestAnimationFrame(animate);

      // 缓慢旋转
      particles.rotation.x += 0.0002;
      particles.rotation.y += 0.0003;

      // 鼠标视差
      const targetX = mouseRef.current.x * 0.5;
      const targetY = mouseRef.current.y * 0.5;
      particles.rotation.x += (targetY - particles.rotation.x) * 0.01;
      particles.rotation.y += (targetX - particles.rotation.y) * 0.01;

      renderer.render(scene, camera);
    };
    animate();

    // ===== 鼠标跟踪 =====
    const onMouseMove = (e) => {
      mouseRef.current.x = (e.clientX / window.innerWidth) * 2 - 1;
      mouseRef.current.y = -(e.clientY / window.innerHeight) * 2 + 1;
    };
    window.addEventListener('mousemove', onMouseMove);

    // ===== 响应式处理 =====
    const onResize = () => {
      camera.aspect = container.clientWidth / container.clientHeight;
      camera.updateProjectionMatrix();
      renderer.setSize(container.clientWidth, container.clientHeight);
    };
    window.addEventListener('resize', onResize);

    return () => {
      cancelAnimationFrame(frameId);
      window.removeEventListener('mousemove', onMouseMove);
      window.removeEventListener('resize', onResize);
      renderer.dispose();
      container.removeChild(renderer.domElement);
    };
  }, []);

  return (
    <div
      ref={containerRef}
      style={{
        position: 'absolute',
        top: 0, left: 0,
        width: '100%', height: '100%',
        zIndex: 0,
        background: 'linear-gradient(135deg, #0F172A 0%, #1E293B 50%, #16213E 100%)',
      }}
    />
  );
}

## 3.4 日志虚拟滚动

### 3.4.1 现状分析

当前 `LogPanel` 组件在对话日志增多时，所有 DOM 节点同时渲染。到数百条日志时会出现明显卡顿，滚动不流畅。

### 3.4.2 优化目标

- 引入虚拟滚动，仅渲染可视区域内的日志条目
- 支持万级日志量流畅 60fps 滚动
- 自适应行高（日志条目高度不固定）

### 3.4.3 实现要点

```

```jsx
// src/components/LogPanel.jsx（改造后）
import { useRef, useMemo } from 'react';
import { useVirtualizer } from '@tanstack/react-virtual';

export default function LogPanel({ logs }) {
  const parentRef = useRef(null);

  // 估算每行高度
  const estimateSize = useMemo(() => {
    return (index) => {
      const log = logs[index];
      // 根据内容长度动态估算
      const len = log.content?.length || 0;
      if (len > 200) return 100;
      if (len > 100) return 72;
      return 48;
    };
  }, [logs]);

  const virtualizer = useVirtualizer({
    count: logs.length,
    getScrollElement: () => parentRef.current,
    estimateSize,
    overscan: 5, // 预渲染 5 条，滚动更平滑
  });

  const items = virtualizer.getVirtualItems();

  return (
    <div
      ref={parentRef}
      className="log-panel"
      style={{ height: '100%', overflow: 'auto' }}
    >
      {/* 撑开总高度 */}
      <div style={{ height: virtualizer.getTotalSize(), position: 'relative' }}>
        {/* 仅渲染可见区域 */}
        <div
          style={{
            position: 'absolute',
            top: 0,
            left: 0,
            width: '100%',
            transform: `translateY(${items[0]?.start ?? 0}px)`,
          }}
        >
          {items.map((virtualItem) => {
            const log = logs[virtualItem.index];
            return (
              <div
                key={virtualItem.key}
                ref={virtualizer.measureElement}
                data-index={virtualItem.index}
                className={`log-item log-${log.type || 'info'}`}
              >
                <span className="log-time">{log.time}</span>
                <span className="log-content">{log.content}</span>
              </div>
            );
          })}
        </div>
      </div>
    </div>
  );
}

    """导出为 PDF（支持中文）"""
    from reportlab.lib.pagesizes import A4
    from reportlab.lib.styles import getSampleStyleSheet, ParagraphStyle
    from reportlab.lib.units import mm
    from reportlab.platypus import SimpleDocTemplate, Paragraph, Spacer
    from reportlab.pdfbase import pdfmetrics
    from reportlab.pdfbase.ttfonts import TTFont
    from reportlab.lib.colors import HexColor
    from io import BytesIO
    import os

    # 注册中文字体（需确保系统有该字体）
    font_paths = [
        "C:/Windows/Fonts/msyh.ttc",       # 微软雅黑
        "C:/Windows/Fonts/simsun.ttc",      # 宋体
        "/usr/share/fonts/truetype/noto/NotoSansCJK-Regular.ttc",  # Linux
    ]
    font_registered = False
    for fp in font_paths:
        if os.path.exists(fp):
            pdfmetrics.registerFont(TTFont('ChineseFont', fp))
            font_registered = True
            break

    if not font_registered:
        # 降级：返回 Markdown
        return _export_markdown(conversations)

    buf = BytesIO()
    doc = SimpleDocTemplate(buf, pagesize=A4, topMargin=20*mm, bottomMargin=20*mm)
    styles = getSampleStyleSheet()

    # 自定义样式
    title_style = ParagraphStyle(
        'ChineseTitle', fontName='ChineseFont', fontSize=18,
        textColor=HexColor('#4A90D9'), spaceAfter=12, alignment=1,
    )
    user_style = ParagraphStyle(
        'ChineseUser', fontName='ChineseFont', fontSize=11,
        textColor=HexColor('#1A1A2E'), spaceAfter=4,
    )
    ai_style = ParagraphStyle(
        'ChineseAI', fontName='ChineseFont', fontSize=11,
        textColor=HexColor('#4A90D9'), spaceAfter=8,
    )

    story = [Paragraph("小文智能助手 · 对话记录", title_style), Spacer(1, 10*mm)]

    for turn in conversations:
        role = turn["role"]
        content = turn["content"].replace('&', '&amp;').replace('<', '&lt;').replace('>', '&gt;')
        content = content.replace('\n', '<br/>')

        if role == "user":
            story.append(Paragraph(f"<b>🧑 用户：</b>{content}", user_style))
        else:
            story.append(Paragraph(f"<b>✨ 小文：</b>{content}", ai_style))

    doc.build(story)
    buf.seek(0)

    return Response(
        buf.getvalue(),
        mimetype='application/pdf',
        headers={"Content-Disposition": "attachment; filename=xiaowen-chat.pdf"}
    )

import { useState, useEffect } from 'react';

export function useMediaQuery(query) {
  const [matches, setMatches] = useState(() =>
    window.matchMedia(query).matches
  );

  useEffect(() => {
    const mq = window.matchMedia(query);
    const handler = (e) => setMatches(e.matches);
    mq.addEventListener('change', handler);
    return () => mq.removeEventListener('change', handler);
  }, [query]);

  return matches;
}
