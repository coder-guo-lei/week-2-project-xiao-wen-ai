# 小文 AI 智能语音助手项目文档

## 一、项目简介

**小文 AI 智能语音助手** 是一个基于 Web 的多功能智能助手项目。项目以“让用户通过文字或语音自然地完成生活查询、AI 对话、音乐播放、图片生成和电脑应用启动”为核心目标，构建了一个具备语音交互、AI 能力和桌面辅助能力的智能助手原型。

项目采用前后端分离架构：

- 前端使用 **React + Vite** 构建交互界面；
- 后端使用 **Python Flask** 提供接口服务；
- AI 对话和图片生成接入 **阿里云百炼 DashScope**；
- 天气查询接入 **高德地图 API**；
- 音乐搜索接入网易云相关接口和备用音乐源；
- **语音识别**使用浏览器 **Web Speech API**；**朗读回复与划词朗读**走后端 **讯飞 TTS**（`POST /api/tts`，默认 WAV）。

目前项目已经形成一个较完整的个人桌面 AI 助手雏形，支持聊天、问答、天气、音乐、绘图、朗读、翻译、模拟世界和打开本机应用等功能。

---

## 二、项目初始目标

项目最初的目标是实现一个可以和用户自然交互的“小文助手”，让用户不需要复杂操作，只需要输入或说出一句自然语言指令，就能完成常见任务。

初始目标主要包括：

1. **自然语言交互**
   - 用户可以直接输入“承德天气如何”“播放稻香”“讲个笑话”等自然语言指令。
   - 系统自动判断用户意图并返回结果。

2. **语音助手体验**
   - 支持语音输入。
   - 支持唤醒词“小文小文”。
   - 支持把小文回复朗读出来。

3. **生活服务能力**
   - 查询天气。
   - 播放音乐。
   - 回答日常问题。

4. **AI 创作能力**
   - 能够进行普通 AI 对话。
   - 能够根据文字生成图片。

5. **桌面辅助能力**
   - 支持打开电脑常用软件，例如记事本、计算器、浏览器、VSCode 等。

6. **可扩展的项目结构**
   - 前端组件化。
   - 后端统一指令解析。
   - 后续可以继续增加更多功能，例如日程、备忘录、知识库、文件总结等。

## 四、已实现功能

### 1. 文字指令输入

用户可以在输入框中输入自然语言指令，并通过 Enter 键或发送按钮提交。

支持能力：

- `Enter` 发送；
- `Shift + Enter` 换行；
- 常用指令历史记录；
- 示例指令快捷发送；
- 发送后自动展示结果；
- 后端未启动时给出错误提示。

示例：

```text
承德天气怎么样
播放稻香
讲个笑话
画一只水彩风格的小猫
打开计算器
```

---

### 2. 语音识别与唤醒词

前端使用浏览器 Web Speech API 实现语音识别。

当前支持两种使用方式：

1. **单次语音识别**
   - 点击“语音”按钮后，系统开始识别用户说的话；
   - 识别完成后自动发送给后端处理。

2. **唤醒词模式**
   - 点击“唤醒”按钮后，系统持续监听；
   - 当听到“小文小文”后，进入指令识别状态；
   - 用户说出命令后自动提交。

适用场景：

- 语音助手；
- 智能桌面控制；
- 无障碍交互；
- 智能音箱 Web 原型。

### 3. AI 对话与连续追问

项目接入阿里云百炼 DashScope 大模型接口，用于普通聊天、问答、讲故事、讲笑话、美食推荐等任务。

已经支持：

- 中文自然回复；
- 适合朗读的口语化回答；
- 闲聊问答；
- 故事和笑话；
- 生活建议；
- 多轮连续对话。

多轮对话示例：

```text
用户：承德美食有哪些？
小文：承德比较有代表性的美食有驴打滚、碗坨、羊汤、拨御面、满族八大碗等。

用户：这些美食在哪个地方能吃到？
小文：如果你想吃这些承德美食，可以去二仙居夜市、南营子大街、避暑山庄周边老店等地方看看……
```

实现方式：

- 前端保存最近几轮聊天记录到 `localStorage`；
- 每次发送聊天请求时，把历史对话一起传给后端；
- 后端对历史记录进行清洗和长度限制；
- 后端调用模型时把历史作为 `messages` 一起发送；
- 后端也保存短期上下文作为刷新后的兜底。

---

### 4. 回复朗读

小文的文字回复通过后端 **讯飞语音合成** 朗读（非浏览器 `speechSynthesis`）。

支持能力：

- 开始朗读 / 停止朗读；
- 女声 /「许久·玉昭」等预设（具体映射见 `backend/routes/api.py` 与 `src/utils/xfyunTts.js`）；
- 音色偏好写入 `localStorage`；
- 文本先经后端清洗（去掉 Markdown、链接、Emoji 等），默认返回 **`audio/wav`**。

实现方式：

- 前端 `playXfyunTts` → `fetch` **`POST /api/tts`**（开发环境经 Vite 代理同源 `/api`）；
- 后端按是否配置 **`XFYUN_SUPER_TTS_WS_URL`** 选择 **超拟人** 或 **在线合成 v2** WebSocket；
- 密钥与接口地址仅写在 **`backend/.env`**，勿写入前端仓库。

说明：发音人须在讯飞控制台对应产品中 **领取/授权**，否则会返回 **11200**；超拟人与在线合成的发音人列表 **不通用**。

### 5. 天气查询

当用户指令中包含“天气”时，后端会识别城市并调用高德地图接口查询天气。

展示内容包括：

- 城市；
- 天气状况；
- 温度；
- 风向风力；
- 湿度。

示例：

```text
北京天气怎么样
承德天气如何
我要保定天气
```

实现方式：

1. 后端从用户指令中提取城市名；
2. 调用高德地理编码接口获取城市编码；
3. 调用高德天气接口获取实时天气；
4. 前端使用 `WeatherCard` 组件展示结果。

### 6. 音乐搜索与播放

用户可以通过自然语言点歌。

示例：

```text
播放稻香
我想听晴天
随便来点音乐
播放周杰伦的歌
```

当前支持：

- 歌曲关键词提取；
- 网易云音乐模糊搜索；
- 备用音乐接口降级；
- 演示音频兜底；
- 播放 / 暂停；
- 上一首 / 下一首；
- 音量调节；
- 进度条跳转；
- 播放列表；
- 播放历史；
- 删除单首歌曲；
- 清空列表。

实现方式：

- 后端负责搜索歌曲并返回音频地址；
- 前端使用自定义 Hook `useMusicPlayer` 管理播放状态；
- 前端使用浏览器原生音频能力播放音乐。

限制：部分歌曲可能受版权、VIP 或外链限制影响，无法正常播放。

### 7. AI 图片生成

用户可以通过自然语言生成图片。

示例：

```text
画一只水彩风格的小猫
生成一个赛博朋克城市夜景
画一个古风少女站在雪地里
```

当前支持：

- 提取绘图 Prompt；
- 调用 DashScope 文生图接口；
- 异步提交图片任务；
- 前端轮询图片生成状态；
- 展示生成中计时；
- 生成完成后展示图片；
- 接口失败时提供兜底提示。

实现方式：

1. 后端识别绘图意图；
2. 后端提交 DashScope 图片生成任务；
3. 后端返回 `task_id`；
4. 前端进入生成中状态；
5. 前端定时请求 `/api/image-status/<task_id>`；
6. 图片成功后展示生成结果。

### 8. 数据可视化图表生成

项目新增了数据可视化能力，用户可以根据文本数据或本地文件生成折线图、柱状图等图表。

示例：

```text
生成折线图 一月:120 二月:180 三月:150 四月:260
生成柱状图 苹果:80 香蕉:120 橙子:60 葡萄:140
标题:月度销售趋势 生成折线图 一月:120 二月:180 三月:150 四月:260
```

支持的文件格式：

- CSV；
- TXT；
- TSV；
- XLSX / XLS。

推荐文件格式：

```csv
月份,销售额
一月,120
二月,180
三月,150
四月,260
```

当前支持能力：

- 根据自然语言中的“名称:数值”自动提取数据；
- 根据纯数字序列生成默认标签；
- 上传 CSV / TXT / Excel 文件生成图表；
- 自动识别折线图和柱状图；
- 自动统计数据量、合计、最大值和最小值；
- 前端使用 SVG 绘制图表，不依赖额外图表库；
- 图表下方保留表格，方便核对原始数据；
- 工作流面板展示“接收数据、解析数据、统计摘要、生成图表”的过程。

实现方式：

1. 后端通过 `is_chart_intent` 判断是否为图表生成指令；
2. 文本数据由 `parse_chart_data_from_text` 使用正则提取标签和值；
3. 文件数据由 `/api/generate-chart` 接收，CSV/TXT 使用 `csv` 模块读取，Excel 使用 `openpyxl` 读取；
4. 后端用 `build_chart_payload` 统一生成 `chartData`；
5. 前端 `App.jsx` 根据 `type: chart` 切换到图表视图；
6. 前端 `ChartPanel` 使用 SVG 绘制折线、柱子、坐标轴、网格线和数据点。

技术说明：

| 技术 / 模块  | 作用                                   |
| ------------ | -------------------------------------- |
| `re`         | 从用户输入中提取“月份:120”这类标签和值 |
| `csv` / `io` | 读取 CSV、TXT、TSV 表格文本            |
| `openpyxl`   | 读取 Excel 文件中的前两列数据          |
| `FormData`   | 前端上传本地数据文件                   |
| SVG          | 前端绘制折线图、柱状图、坐标轴和点位   |
| `useMemo`    | 缓存图表坐标计算结果，提高渲染效率     |

限制说明：

- 当前默认读取文件前两列，第一列为名称，第二列为数值；
- 单次最多展示前 80 条数据，避免图表过密；
- 文件大小限制为 2MB；
- 目前是单系列图表，后续可扩展为多系列折线图、饼图、面积图和导出功能。

### 10. 文字模拟世界

项目实现了一个轻量级文字模拟世界功能。

用户可以生成一个随机主题世界，例如修仙、末日、奇幻，并在其中进行探索、生存和行动。

示例：

```text
生成一个修仙世界，世界种子随机，把我出生在那里
继续探索
采集资源
修炼
查看状态
退出模拟
```

功能特点：

- 随机生成世界种子；
- 随机生成出生地点；
- 随机生成初始资源；
- 支持生命、精力、饥饿、安全、机缘、敌意等状态；
- 支持探索、采集、休息、战斗、交易、修炼等行动；
- 进入模拟世界后会锁定上下文；
- 输入“退出模拟”后回到普通助手模式。

### 11. 划词翻译与朗读

用户在页面中选中文字后，可以使用悬浮工具条进行处理。

支持：

- 翻译成中文；
- 翻译成英文；
- 朗读原文；
- 朗读译文；
- 停止朗读；
- 复制译文。

实现方式：

- 前端监听用户选中文本；
- 后端 `/api/translate-selection` 调用大模型完成翻译；
- **朗读原文/译文**与回复区相同，调用 **`POST /api/tts`**（讯飞），音色取自 `localStorage` 中的预设键。

### 13. 告别与重置界面

用户说出类似“再见小文”“小文休息吧”等指令时，系统会执行重置流程。

行为：

1. 后端识别告别意图；
2. 返回告别语；
3. 前端先展示告别回复；
4. 延迟后清空当前天气、音乐、图片、模拟世界和对话状态；
5. 页面回到初始引导界面；
6. 清空多轮对话上下文。

### 2. 后端技术

| 技术                      | 用途                                          |
| ------------------------- | --------------------------------------------- |
| Flask                     | 提供 HTTP API 服务                            |
| Flask-CORS                | 解决前后端跨域问题                            |
| requests                  | 调用第三方接口                                |
| python-dotenv             | 读取 `.env` 环境变量                          |
| zhdate                    | 农历与公历换算（1900–2100），写入对话系统提示 |
| DashScope                 | AI 对话和 AI 文生图                           |
| DeepSeek（可选）          | OpenAI 兼容对话 / 翻译兜底                    |
| 高德地图 API              | 城市天气查询                                  |
| subprocess / os.startfile | 启动本机白名单应用                            |
| csv / io                  | 解析 CSV、TXT、TSV 数据文件                   |
| openpyxl                  | 解析 Excel 数据文件                           |
| websockets（asyncio）     | 讯飞 TTS：在线合成 v2 或超拟人 WebSocket      |

主要接口：

| 接口                          | 方法 | 说明                                                                          |
| ----------------------------- | ---- | ----------------------------------------------------------------------------- |
| `/api/send-task`              | POST | 接收用户指令，返回对应功能结果                                                |
| `/api/image-status/<task_id>` | GET  | 查询图片生成状态                                                              |
| `/api/generate-chart`         | POST | 上传 CSV / TXT / Excel 文件并生成图表数据                                     |
| `/api/translate-selection`    | POST | 对划词内容进行翻译                                                            |
| `/api/tts`                    | POST | JSON：`text`、`voice` → 讯飞合成音频（默认 WAV），详见 `backend/.env.example` |

后端核心逻辑：

1. 接收用户指令；
2. 判断是否为告别、模拟世界、天气、音乐、图片、图表、应用、网页或普通聊天；
3. 调用对应服务；
4. 返回统一 JSON 数据；
5. 前端根据 `type` 字段切换展示组件。

常见返回类型：

| type            | 说明               |
| --------------- | ------------------ |
| `chat`          | 普通聊天或文字结果 |
| `weather`       | 天气查询           |
| `music`         | 音乐播放           |

## 七、项目亮点

1. **功能综合性强**
   - 集成了聊天、语音、天气、音乐、绘图、图表、翻译、朗读、本机应用启动等多种能力。

4. **支持多轮对话**

5. **异步图片生成体验更好**
   - 图片生成使用任务轮询机制，不会让前端长时间无响应。

6. **具备桌面控制能力**
   - 可以安全地打开白名单中的本机应用。

7. **数据可视化能力**
   - 支持根据文本或文件快速生成折线图、柱状图，并自动给出摘要统计。

8. **前后端分离，便于扩展**
   - 前端组件化；
   - 后端集中指令解析；
   - 后续新增功能相对方便。

## 八、当前限制

1. **语音识别依赖浏览器支持**
   - 建议使用 Chrome 或 Edge。

2. **音乐播放受版权和外链限制影响**
   - 部分歌曲可能无法播放。

3. **AI 图片生成受网络和模型速度影响**
   - 图片生成可能需要数秒到几十秒。

4. **意图识别主要依赖关键词规则**
   - 对复杂表达可能存在误判。

5. **本机应用启动依赖 Windows 环境**
   - 部分应用需要安装并配置系统路径或快捷方式。

6. **图表功能当前为单系列数据**
   - 暂时默认读取前两列，后续可扩展多系列图表和导出功能。

7. **Flask 当前为开发模式**
   - 正式部署时应关闭 `debug=True`。

## 十一、交付版配置与行为补充（2026）

本节汇总近期加固项，与「环境配置」「技术方案」对应阅读即可。

### 1. 双模型与密钥

| 变量                       | 作用                                                              |
| -------------------------- | ----------------------------------------------------------------- |
| `DASHSCOPE_API_KEY`        | 阿里云百炼：对话、文生图、VL、翻译主链路                          |
| `DEEPSEEK_API_KEY`（可选） | OpenAI 兼容接口：对话 / 翻译 / 知识库兜底，不能替代百炼生图与看图 |
| `AMAP_KEY`                 | 高德：天气、地理编码（仅后端使用）                                |

### 2. 时间与农历可信性

- **`LOCAL_TIMEZONE`**（IANA，默认 `Asia/Shanghai`）：服务端「此刻」的公历依据。
- **农历**：依赖 Python **`zhdate`**（已写入 `backend/requirements.txt`）。系统提示除「今天对应的农历」外，还提供 **当前农历年内锚点**（如正月初一、三月廿六、五月初五、八月十五）的 **公历对照**，避免模型将「阴历生日」错算成错误公历。
- **实现入口**：`backend/app.py` 中 `current_datetime_context_for_llm()`、`lunar_year_anchor_facts_for_llm()`。

### 3. 前端体验

- **指令输入框**：发送结束或单次语音识别结束后自动重新聚焦，减少重复点击（`CommandInput.jsx`）。
- **语音**：单次聆听约 **20 秒**内若引擎完全无文字则超时（`useVoiceRecognition.js` 中 `CMD_NO_INPUT_MS`）；有字后约 **2.8 秒**无新变化则提交。
- **吉祥物「小文机器人」**：可拖拽、投掷与边缘反弹，位置存 `localStorage`（`XiaowenBot.jsx`）。
- **开发代理**：`vite.config.js` 将 `/api` 代理到 `127.0.0.1:5001`，朗读与对话同源请求更稳定（`xfyunTts.js` 在 dev 下使用 `/api/tts`）。

### 4. 仓库根目录文档

根目录 [README](../README.md) 提供仓库结构、启动命令与 PPT 生成说明；运行 `python generate_xiaowen_ppt.py` 得到 `xiaowen-report-final.pptx`。

## 十二、安全与隐私说明

1. `.env` 中包含 API Key，不应上传到公开仓库；

## 十三、项目总结

小文 AI 智能语音助手从最初的“能通过语音或文字与用户交流”的目标，逐步扩展为一个集成多种能力的智能助手系统。

当前项目已经具备：

- 能听：语音识别和唤醒词；
- 能说：回复朗读和划词朗读（讯飞 TTS）；
- 能聊：AI 对话和连续追问；
- 能查：天气查询；
- 能放：音乐搜索与播放；
- 能画：AI 文生图；
- 能看：根据文本或文件生成数据图表；
- 能开：打开本机常用应用；
- 能玩：文字模拟世界；
- 能译：划词翻译。

从技术角度看，项目整合了 React 前端、Flask 后端、AI 模型调用、语音识别、语音合成、音乐播放、异步图片任务、数据可视化和本机应用控制，具有较强的学习价值和扩展价值。

从后续发展看，小文可以继续向个人桌面 AI 助手、AI 工作台、智能音箱原型和教学展示项目方向发展。只要继续增强意图识别、长期记忆、模块化架构和部署能力，就可以逐步成长为更完整、更实用的智能应用平台。
