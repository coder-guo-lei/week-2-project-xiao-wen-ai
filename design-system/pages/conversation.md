# 小文 AI — 对话页覆盖规则

> 继承 MASTER.md，以下规则优先级更高。

## 对话面板特化

| 规则 | 覆盖值 | 原因 |
|------|--------|------|
| 对话卡片圆角 | `--radius-lg` (20px) 代替 `--radius-md` | 对话气泡需要更圆润，贴合聊天感 |
| 消息间间距 | `--space-3` (12px) | 对话密度高于普通卡片，需要紧凑 |
| 输入框高度 | ≥ 48px（含 padding） | 移动端触控 ≥ 44pt 最低要求 |
| AI 回复背景 | `var(--surface)` | 凸起态，区分用户消息（凹陷态） |
| 用户消息背景 | `var(--accent-bg)` + `var(--accent-light)` | 微弱主色底，视觉方向区分 |
| 代码块 | `var(--surface-sunken)` + `var(--font-mono)` | 凹陷 + 等宽，代码专属 |
| 打字指示器 | 三圆点 pulse，300ms 间隔 | 比传统「正在输入…」更柔和 |

## TTS 播放按钮

- 使用 `--accent` 圆形按钮，`--radius-full`
- 播放中：波形动画替换 Icon（4 条竖线动态高度）
- 最小触控面积 44×44pt（用 padding 补足）
