# 小文 AI — 工具卡覆盖规则

> 继承 MASTER.md，以下规则优先级更高。

## 工具卡（图片理解 / 摄像头 / 天气等）

| 规则 | 覆盖值 | 原因 |
|------|--------|------|
| 工具卡圆角 | `--radius-md` (14px) | 内嵌面板，圆角小于外层卡片 |
| 边框 | 虚线 `var(--tool-card-dash)` | 区分工具区与普通内容区 |
| 图标尺寸 | 24px `--text-2xl` 行高 | 工具图标需醒目但不抢主内容 |
| 工具卡内 padding | `--space-4` (16px) | 比外层卡片紧凑 |
| 展开态 | 平滑 max-height 过渡 300ms | 避免突兀出现/消失 |

## 面部检测 / 图像分析

- 摄像头视图圆角 `--radius-md`
- 检测框描边：`var(--accent)` 2px，圆角 4px
- 实时帧率提示：`--text-xs` + `--text-tertiary`，不干扰主视图
